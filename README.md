# PROJECT 5 – STRING-BASED EXAMINATION ANSWER EVALUATION

## About the Project
The String-Based Examination Answer Evaluation project is designed to evaluate a student's answer by comparing it with a predefined correct answer. It uses string operations to check matching words and calculate the similarity between the student's answer and the expected answer. Based on the matching results, it calculates and displays the evaluation score.

## Technologies Used
- **Python** – Used to develop the answer evaluation program.
- **Strings** – Used to store and process examination answers.
- **Lists** – Used to separate answers into individual words.
- **Loops** – Used to compare words in the answers.
- **Conditional Statements** – Used to check matching words.
- **String Methods** – Used to process and compare text.

## Main Features
- Accepts the correct answer.
- Accepts the student's answer.
- Converts answers into individual words.
- Compares the words in both answers.
- Identifies matching words.
- Calculates the answer evaluation score.
- Displays the final evaluation result.

## Algorithm
1. Start the program.
2. Enter the correct answer.
3. Enter the student's answer.
4. Convert both answers into lowercase.
5. Split both answers into individual words.
6. Compare the words in the student's answer with the correct answer.
7. Count the matching words.
8. Calculate the evaluation score.
9. Display the matching words and final score.
10. Stop the program.

## Sample Output
```text
Enter correct answer: Python is a programming language
Enter student answer: Python is a popular programming language

----- ANSWER EVALUATION REPORT -----

Total Words: 5
Matching Words: 4
Evaluation Score: 80%

Result: Good Performance
```

## Conclusion
This project helps evaluate examination answers using basic string comparison techniques. It demonstrates Python concepts such as strings, lists, loops, conditional statements, and string methods to perform simple automated answer evaluation.
